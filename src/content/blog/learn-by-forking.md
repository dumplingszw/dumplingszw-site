## 为什么 Fork

很多优秀的开源项目，光看 README 是学不到东西的。把它们 Fork 到自己的账号下，有几点好处：

- 可以**直接运行**，用起来才知道它解决了什么问题
- 可以**随便改**，坏了也不怕
- 关注列表里能看到作者后续的更新

## 我的做法

1. 找感兴趣的项目，先 Fork
2. 本地跑通，哪怕只是 `npm install && npm run dev`
3. 挑一个文件读，顺着 import 搞清楚调用链
4. 试着改一个小功能，验证自己的理解

## 提醒

Fork 不等于抄袭。学习用途随便看，但要公开发布时记得遵守原项目的开源协议。
