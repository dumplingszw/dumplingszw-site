## 什么是 Agent

Agent 可以理解为「能自主完成目标的程序」：它感知环境、做规划、调用工具、观察结果、再迭代，直到任务完成。

## 一个最小闭环

1. **感知（Perceive）**：读取用户输入与当前上下文。
2. **规划（Plan）**：决定下一步要做什么，是否需要调用工具。
3. **行动（Act）**：执行动作，比如调用一个 API、运行一段代码。
4. **观察（Observe）**：拿到结果，回到第 2 步。
