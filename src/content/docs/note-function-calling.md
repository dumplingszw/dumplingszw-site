**Function Calling**（函数调用）让模型不再只输出文字，而是输出「要调用哪个函数、参数是什么」。

流程：

- 你给模型一份「工具清单」（函数名 + 参数 schema）
- 模型判断该不该调用、传什么参数
- 你的程序真正执行函数，把结果喂回模型
- 模型据此继续生成回答

这是把 LLM 接入真实世界（查数据库、发请求、跑代码）的桥梁。
